# Карточка ноды

Всё об одной ноде на одной странице: состояние, подходящие группы, последние результаты, трафик, события и действия. Карточка
открывается щелчком по ключу ноды в любой таблице; в её адресе — ключ (`#/nodes/8d31a426.0be1f7a2`), так что ссылка на карточку
действует, пока нода существует. Карточка ноды, ушедшей из подписок, открывается из [архива](nodes.ru.md#archive).

<a id="header"></a>
## Шапка

- полный тег ноды с ключом в двух цветах ([что такое ключ](concepts.ru.md#nodes));
- имя ноды в подписке;
- у [цепочки](checks.ru.md#entry) — страна входа → страна выхода с IP и сетями (ASN) входа и выхода и выход через Cloudflare WARP;
  у прямой ноды — её единственный IP;
- значки: группы ноды и её [клиентские группы](subscriptions.ru.md#client-groups), группы, в резерве которых нода, присутствие
  в списке, рейтинг, ограничения, «Выбрана переключателем»;
- для ноды на паузе или в карантине — до какого времени, после этого она снова проверяется.

«Выбрана переключателем» — выбор тестера. Он не доказывает, что селектор sing-box действительно указывает на ноду или что через неё идёт
трафик.

Вкладки под шапкой хранятся в адресе (`?tab=groups`).

<a id="state"></a>
## Вкладка «Состояние»

**Изменение рейтинга** — график последних 24 значений рейтинга. **Замеры рейтинга** — все сохранённые значения с датой и временем;
период можно ограничить полями «С» и «По».

**Технические сведения** (после входа):

- JSON ноды как в `nodes.json`, в двух цветах: синие поля входят в первую часть ключа (настройки сервера), фиолетовые — во вторую
  (учётные данные); неокрашенные поля (`tag`, `domain_resolver`) в ключ не входят;
- **Проверка ключа**: ключ, пересчитанный по этому JSON; «✓ OK» — совпадает; расхождение значит, что нода в базе и в `nodes.json`
  различаются (например, после смены формата);
- **Строки для CRC32** — ровно то, что хэшируется для каждой части;
- если ноды уже нет в `nodes.json`, JSON восстанавливается из базы, и полей вне ключа, кроме `tag`, в нём нет;
- причина ограничения и число провалов подряд.

<a id="groups"></a>
## Вкладка «Группы»

Для каждой группы — состояние ноды в ней и вердикт каждой проверки группы.

| Состояние | Что значит |
|---|---|
| активна | нода выбрана в группе сейчас |
| в резерве | проверена заранее, чтобы заменить активную |
| кандидат | может стать активной ([условия](groups.ru.md#candidates)) |
| не кандидат | входит в группу, но не проходит обязательную проверку, ограничена или у неё рейтинг 0 |
| не входит | нет в селекторе группы |

Проверки: ✓ пройдена, ✗ провалена, ? нет свежего результата. Желательные проверки помечены; во всплывающей подсказке — возраст
результата. Группа без проверок принимает любую рабочую ноду. Нода становится активной, только если все обязательные проверки свежие и
пройдены; желательные поднимают её в очереди ([ярусы](groups.ru.md#tiers)).

<a id="results"></a>
## Вкладка «Результаты»

Последний результат каждого замера и проверки со временем получения и сведения ip-api о последнем IP выхода: его тип с сетью (ASN) и
совпадает ли страна по базам с измеренной. У провала причина названа словами, а в «Подробностях» — текст ошибки и ошибка sing-box
по соединению тестера за время проверки:

| Причина | Что произошло |
|---|---|
| DNS | sing-box не смог разрешить имя сервера ноды |
| TLS | не прошла проверка сертификата сервера или Reality |
| TCP | нет TCP-соединения с сервером ноды: таймаут, отказ, нет маршрута |
| Транспорт | сервер ноды ответил транспорту (WebSocket, XHTTP) ошибкой HTTP |
| Рукопожатие | TCP соединился, но рукопожатие протокола зависло: блокировка на пути или мёртвый сервер |
| Сброс | соединение сброшено или закрыто другой стороной |
| Замерла | передача остановилась на середине |
| Медленно | скорость ниже порога |
| Отказ сервиса | AI-сервис отказал по региону или лимиту; туннель работает |
| Цель проверки | сервер проверки ответил ошибкой (404, 5xx): нода не виновата |
| Нет ответа | запрос не дождался ответа, ошибки sing-box нет |

Отсутствие результатов не означает провала: ноду могли ещё не измерить. Смысл каждого значения — на странице [Результаты](nodes.ru.md#results).

<a id="traffic"></a>
## Вкладка «Трафик»

Входящий и исходящий пользовательский трафик через ноду за сохранённый период. Отсутствие сохранённого трафика не доказывает, что нода
не использовалась: проверьте, включён ли сбор трафика (`storage.traffic.enabled`), и срок хранения.

<a id="events"></a>
## Вкладка «События»

- **Ограничения и присутствие** — события ноды из последних 500 записей общего журнала событий: пауза, карантин, восстановлена,
  исключена, исключение снято, ограничение снято, исчезла из списка; кто сделал — автоматически или администратор.
- **Переключения** — записи последних 200 переключений, где участвует нода.

<a id="actions"></a>
## Вкладка «Действия»

Каждое действие спрашивает подтверждение и требует токен администратора.

| Действие | Что происходит |
|---|---|
| Исключить / Снять исключение | нода бессрочно исключается из проверок; если она активна, её группы сразу переходят на другую ноду ([исключение](restrictions.ru.md#ban)) |
| В карантин | проверки откладываются на `selection.quarantine.duration`; активная нода сразу заменяется |
| Снять ограничение | пауза или карантин снимаются, нода встаёт в очередь проверки; ручное исключение остаётся |
| Выбрать в группе | нода становится активной в выбранной группе сейчас ([ручной выбор](switching.ru.md#manual)) |

«Выбрать в группе» предлагает только группы, где нода — кандидат: положительный рейтинг, все обязательные проверки пройдены, нет
ограничений. Если таких нет, действие недоступно. Автоматика продолжает работать и может позже сменить выбор.
