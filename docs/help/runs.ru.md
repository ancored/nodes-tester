# Проверки

Эта страница показывает, чем занят тестер, и его журнал, а также запускает тестирование всех нод по требованию. Нужны токен
администратора и встроенная админка (у отдельной админки нет живого тестера).

<a id="status"></a>
## Проверки текущих нод sing-box

| Строка | Что значит |
|---|---|
| Этап | «Проверка ноды», «Ожидание сроков тестов», «Ожидание применения конфига», «Подготовка», «Остановлен» |
| Текущая нода | нода, которая проверяется |
| Тестирование по требованию | сколько нод осталось, пока оно идёт |
| Текущее ожидание до | когда истечёт следующий результат; срок может сдвинуться при появлении новых нод |
| Следующая ротация | ближайший срок [ротации](switching.ru.md#rotation) среди всех групп |
| Монитор активных нод · сбор трафика | работают ли потоки [монитора](switching.ru.md#monitor) и учёта трафика |

Тестер проверяет только ноды с истёкшими результатами ([сроки жизни и очередь](checks.ru.md#lifetimes)). Состояние обновляется каждые
5 секунд.

<a id="run-now"></a>
### Запустить тестирование сейчас

Кнопка ставит в очередь все доступные тестеру ноды, не дожидаясь их сроков: пригодится после смены тестов или порогов или чтобы увидеть
состояние всех нод сейчас. Она не загружает подписки и не собирает и не применяет конфигурацию. Пока идёт тестирование по требованию,
кнопка недоступна. Полный круг по многим нодам занимает время: каждая нода — несколько секунд, а ноды одного хоста разнесены на
`tester.host_gap`.

<a id="log"></a>
## Журнал тестера

Последние строки журнала тестера, обновляются каждые 2 секунды; на странице хранится до 1500 строк, у сервера ограниченный буфер, так
что после долгой паузы старые строки могут выпасть. Полный журнал — на роутере: `logread -e nodes-tester`.

- **Поиск** фильтрует строки по тексту.
- **Строки**: все, ошибки или переключения. Тип угадывается по тексту строки; это не структурированный уровень журнала.
- **Приостановить чтение** перестаёт подтягивать новые строки (например, чтобы прочитать длинную ошибку); **Следовать за новыми
  строками** прокручивает к концу.

Что значат основные строки:

| В строке | Что значит |
|---|---|
| `[switch] <группа>: EMERGENCY / QUALITY / ROTATION → <нода>` | [переключение](switching.ru.md#reasons) |
| `кандидатов нет … группа на failsafe-out` | группа потеряла кандидатов ([запасной выход](groups.ru.md#fallback)) |
| `gate-провал … пауза #n` / `карантин` | провал gate и следующее за ним [ограничение](restrictions.ru.md) |
| `[reserve]` | процесс резерва проверяет претендентов |
| `[monitor]` | пробы активных нод |
| `[rebuild]` | тестер сам запускает конвейер роутера ([пересборка при деградации](switching.ru.md#rebuild)) |
| `[amnezia]` | сверка стран [Amnezia Premium](subscriptions.ru.md#amnezia) |
