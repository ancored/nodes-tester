# Справка nodes-tester

Полное руководство по nodes-tester: как он устроен внутри и что показывает каждая страница и каждый блок админки. Этот же текст
встроен в админку: иконка **?** рядом с заголовком страницы или в углу блока открывает нужный раздел в боковой панели, а пункт меню
«Справка» — всю справку с оглавлением и поиском. Работает без интернета.

<a id="start"></a>
## С чего начать

Если вы настраиваете nodes-tester впервые, идите по порядку:

1. **Установите пакет** и подключите sing-box: [установка на OpenWrt](../../openwrt/README.ru.md).
2. **Войдите** в админку с токеном администратора: [Доступ и интерфейс](access.ru.md#login).
3. **Добавьте подписки** на странице [«Подписки и сборка»](subscriptions.ru.md), вкладка «Источники подписок».
4. **Опишите группы** там же, вкладка «Сборка и группы»: какие страны, ИИ-сервисы и типы IP нужны каждой группе
   ([Группы и кандидаты](groups.ru.md)).
5. **Запустите конвейер** на странице [«Конвейер»](pipeline.ru.md): сначала проверка, потом применение; включите расписание.
6. **Включите нужные пресеты правил** на странице [«Правила»](rules.ru.md) и примените их.
7. **Следите** за [«Обзором»](overview.ru.md): за несколько минут тестер измерит ноды и выберет активную ноду каждой группы. Если
   что-то не так — [Неполадки](troubleshooting.ru.md).

<a id="conventions"></a>
## Обозначения

- `selection.reserve` — путь поля в `config.json`: поле `reserve` раздела `selection`. Имена полей ведут в
  [справочник](../CONFIG.ru.md).
- Длительности записываются как в sing-box: `30s`, `5m`, `3h`, `2d`.
- «Нода» — один прокси-сервер со своими учётными данными; «группа» — selector sing-box, которым управляет тестер. См.
  [словарь](concepts.ru.md#glossary).
- Значения по умолчанию указаны для новой установки; ваш `config.json` может их переопределять.
