# Доступ и интерфейс

Эта страница — о том, что общее для всех страниц админки: доступ, обновление данных, таблицы, язык и сама справка.

<a id="modes"></a>
## Просмотр и администрирование

Админка открывается в **режиме просмотра**: видно всё состояние, замеры и историю (если включён `admin.public_read`, как по
умолчанию), но ничего нельзя изменить. Для настроек, конвейера, файлов sing-box и действий с нодами нужен токен администратора.

| Без токена | С токеном |
|---|---|
| обзор, ноды, рейтинг, результаты, переключения, трафик | всё из режима просмотра |
| — | настройки и подписки, конвейер и его журналы, правила и файлы sing-box |
| — | действия с нодами: исключить, в карантин, выбрать в группе |
| — | журнал тестера, тестирование по требованию, остановка sing-box, `VACUUM` |
| — | JSON ноды в карточке |

История конвейера, его журналы и исходные файлы sing-box без токена не показываются никогда: в них могут быть адреса подписок.

<a id="login"></a>
## Вход

Нажмите «Войти для управления» в шапке и введите токен из `admin.token` файла `config.json` на роутере (его создаёт установка пакета;
по SSH: `grep token /etc/nodes-tester/config.json`). Это **не** секрет API sing-box. Токен проверяет сервер; сам по себе ввод доступа
не даёт.

- Без «Запомнить на этом устройстве» токен живёт, пока открыта страница.
- С ним токен хранится в браузере (localStorage). Не включайте на чужом компьютере.
- «Выйти» удаляет сохранённый токен и закрывает редакторы. Если есть несохранённые изменения, админка сначала спросит.
- Если на сервере нет токена (`admin.token` пуст), правка и управление выключены; форма входа об этом скажет.

Передавайте токен только по доверенной сети или HTTPS: внутри LAN админка работает по обычному HTTP. Не выставляйте админку в
интернет. См. [модель безопасности](../SECURITY_MODEL.ru.md).

<a id="standalone"></a>
## Встроенная и отдельная админка

Обычно админка работает внутри процесса тестера (встроенная). Её можно запустить и отдельно (`python3 -m dashboard`): тогда она читает
базу и файлы и правит `config.json`, но живого тестера у неё нет — тестирование по требованию, журнал, живое состояние селекторов и
действия с нодами недоступны. В этом режиме админка показывает предупреждение.

<a id="refresh"></a>
## Обновление данных

Данные — снимок базы: сервер делает новый раз в `admin.refresh` (10 с), а страница запрашивает его каждые 15 секунд и по кнопке
«Обновить». В шапке — время снимка.

- Если сервер не отвечает, в шапке «Нет свежих данных», а страница продолжает показывать последний снимок с предупреждением и его
  временем. Устаревший снимок не подтверждает текущее состояние.
- Если база недоступна (неверный `storage.path`, тестер её ещё не создал), страница об этом скажет: пустые списки тогда не значат, что
  нод нет.

<a id="tables"></a>
## Таблицы

Все таблицы работают одинаково:

- **Поиск** ищет текст во всех столбцах строки: имя, провайдера, код страны, часть ключа.
- **Фильтры** — выпадающие списки: страна, группа резерва, протокол, провайдер и поля конкретной таблицы (состояние, статус,
  причина). «Сбросить фильтры» очищает их.
- **Сортировка**: щелчок по заголовку столбца (один — по возрастанию, два — по убыванию, три — исходный порядок) или выбор в списке
  «Сортировка».
- **Страницы** — стрелки под таблицей.
- Поиск, фильтры, сортировка и страница хранятся в адресе страницы: ссылка открывает тот же вид, а автообновление его не сбрасывает.

Ключ ноды в таблицах показан в две строки и двумя цветами: первая часть (синяя) — контрольная сумма настроек сервера, вторая
(фиолетовая) — учётных данных ([Ноды и их ключи](concepts.ru.md#nodes)). Щелчок открывает [карточку ноды](node-card.ru.md). Страна
показана флагом, код — во всплывающей подсказке. Протокол разбит на части, по одной в строке.

<a id="language"></a>
## Язык

Интерфейс — на английском и русском. По умолчанию выбирается язык браузера; выбор в списке «Язык» внизу меню запоминается на устройстве.
Справка следует тому же языку. Сообщения, приходящие с сервера (часть ошибок, журналы тестера и конвейера), пока на русском.

<a id="dashboard"></a>
## sing-box dashboard

Пункт меню «sing-box dashboard» открывает в новой вкладке официальную панель API-сервиса sing-box: живые соединения, селекторы, журнал
самого sing-box. Админка раздаёт её по адресу `/sing-box-dashboard/` из `{api.url}/dashboard/`, поэтому у API-сервиса должен быть задан
`dashboard`. После входа администратора админка записывает адрес и секрет API в настройки панели в браузере, и панель открывается без
вопросов. На чужом компьютере не входите или удалите сервер в настройках панели: секрет остаётся в браузере.

<a id="help"></a>
## Справка

- Иконка **?** рядом с заголовком страницы открывает справку страницы; иконка в углу блока — раздел об этом блоке. Справка открывается
  в боковой панели поверх страницы; закрывается Esc или ✕.
- «Открыть всю справку» в панели или пункт меню «Справка» открывают страницу справки с оглавлением слева и поиском по всем разделам.
- Справка входит в пакет и работает без интернета. Тот же текст лежит в папке `docs/help` репозитория.
