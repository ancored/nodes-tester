# Переключения

История выбора активной ноды каждой группы. Как переключатель принимает решения, объяснено в разделе [Переключения](switching.ru.md).

<a id="active"></a>
## Активные ноды по группам

Нода, выбранная сейчас в каждой группе работающим тестером. Если тестер не подключён (отдельная админка), блок недоступен, но история
ниже всё равно показывается.

<a id="history"></a>
## История

Последние 200 записей по всем группам, сначала новые.

| Столбец | Что значит |
|---|---|
| Дата и время | когда произошло переключение |
| Группа | группа |
| Выбранная нода | нода, ставшая активной (или запасной выход) |
| Предыдущая нода | нода до неё; ссылка открывает её карточку (полный тег виден, пока нода в списке или в архиве) |
| Причина | почему (см. ниже); значок помогает их различать |
| Активная нода | «● Активна» — последняя запись ноды, которая активна в группе сейчас; её строка зелёная |

| Причина | Что значит |
|---|---|
| Первый выбор | у группы не было активной ноды (запуск тестера, новая группа) |
| Аварийная замена | активная нода умерла, ограничена или потеряла обязательную проверку |
| Авария: замена не найдена | активная нода мертва, а переключаться не на что; переключения не было |
| Смена по качеству | нода лучше удержала перевес |
| Плановая ротация | наступил срок ротации |
| Ручной выбор | ноду выбрал администратор |
| Кандидатов нет — запасной выход | группа ушла на `failsafe-out`, `block-out` или `direct-out` |

Фильтры выбирают группу и причину. Последняя запись группы не всегда показывает текущую активную ноду: авария без замены — не
переключение. Частые аварии в одной группе значат, что её ноды блокируют: посмотрите [качество провайдеров](nodes.ru.md#provider-quality)
и [ограничения](nodes.ru.md#paused).

Какие переключения приходят уведомлениями, задаётся в [Настройках → Уведомления](settings.ru.md#notifications): по умолчанию только
аварийные.
