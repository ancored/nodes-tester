## Разработка

```sh
cd web
npm install
npm run dev
```

Vite перенаправляет `/api` на локальный Python-сервер согласно `vite.config.js`. Для
полноценной проверки действий нужен встроенный dashboard с живым Runner; отдельный сервер
подходит для просмотра и работы с файлами.

## Сборка

```sh
cd web
npm run test
npm run build
```

`npm run test` запускает unit-тесты Node и проверку рендера (каждая страница на обоих языках). `npm run build` пишет файлы
не в `web/dist`, а сразу в `dashboard/static`. После изменения интерфейса нужно коммитить
исходники и обновлённую статику вместе.

## Устройство

| Путь | Назначение |
|---|---|
| `src/router.js` | разделы, вложенная навигация по нодам и карточка ноды |
| `src/store.js` | общий снимок данных и автообновление |
| `src/api.js` | HTTP, токен, сессия и обработка ошибок |
| `src/i18n.js`, `src/locales/` | язык интерфейса и русский каталог |
| `src/query.js` | состояние фильтров, сортировки и страницы в URL |
| `src/status.js` | единый словарь статусов ноды |
| `src/ux.js` | общие пользовательские проверки и сообщения, умолчания форм из схемы |
| `src/components/` | таблица, легенда, действия над нодой и другие блоки |
| `src/views/` | страницы админки |

Страницы `Pipeline.vue`, `Singbox.vue` и `Presets.vue` доступны во встроенной админке с
токеном и оркестратором. Конвейер различает проверку и применение, показывает историю
и журналы. Редактор проверяет базу sing-box перед записью и хранит прошлые версии файлов;
сохранение не запускает применение.

Router использует hash-history, поэтому статический сервер не должен знать маршруты SPA.
Фильтры и сортировка хранятся в URL и переживают автообновление данных.

Страна в таблицах показывается флагом, код — во всплывающей подсказке. Флаги рисует шрифт
«Twemoji Country Flags» из пакета `country-flag-emoji-polyfill` (код — MIT, изображения
флагов — [Twemoji](https://github.com/twitter/twemoji), CC-BY 4.0); он входит в сборку и
загружается только браузерами, которые не умеют рисовать флаги сами (Windows).

## Два языка

Строки в коде — на английском и проходят через `t()` из `src/i18n.js`; перевод — каталог
`src/locales/ru.js`, ключ в нём — английская строка. Параметры пишутся как `{name}`:
`t('Snapshot {time}', { time })`. Разметка внутри переводимой фразы — через компонент `Msg` с
именованными слотами. Нет перевода — показывается английский текст. Язык по умолчанию — язык
браузера, выбор в меню хранится в `localStorage` (`nt_lang`); даты и сортировка используют
локаль выбранного языка.

`tests/i18n.test.js` проверяет, что у каждой строки, переданной в `t()`, есть перевод, в каталоге нет
лишних ключей и дублей, параметры совпадают, а кириллицы в коде вне каталога нет (кроме
комментариев и строк с пометкой `i18n-skip`). Добавляете строку — добавьте её перевод в `ru.js` в
той же правке.

## Правила интерфейса

- отсутствие данных не следует выдавать за нулевое значение;
- рейтинг и физические метрики показываются отдельно;
- опасные действия требуют подтверждения и объясняют последствия;
- интерфейс различает отдельный dashboard и встроенный Runner;
- токен администратора не подставляется в URL и может храниться только по явному выбору;
- сохранение подписок не изображается как применение новых нод к sing-box;
- пустое поле настроек показывает серым значение по умолчанию из `config.schema.json` и в файл не пишется.
